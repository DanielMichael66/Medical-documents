# Medical Certificate Generator

A simple open-source medical certificate generator built with **HTML, CSS and JavaScript**.

It demonstrates how a browser-based form can create a printable sample medical certificate without a backend.

## Live Project

For a more complete medical document toolkit, visit **[MedCertGen](https://medcergen.com/)**.

## Features

- Responsive interface
- Patient and certificate details form
- Live sample certificate preview
- Print-friendly output
- No backend required
- No external JavaScript libraries
- Basic HTML escaping for user-entered text
- Responsible-use notice

## Files

- `index.html` — page structure and form
- `style.css` — responsive styling
- `script.js` — certificate generation and printing

## Run Locally

1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Fill in the form.
4. Click **Generate Sample**.
5. Use **Print** to print or save the sample as PDF.

## Responsible Use

This project is for educational, prototyping and creative purposes. It does not issue genuine medical certificates and must not be used to misrepresent a document as being issued by a qualified healthcare professional.
